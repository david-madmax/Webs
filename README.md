# Corralón El Martillo

Landing comercial estática para Corralón El Martillo, Villa Dos Trece, Formosa.

## Ejecutar

Abrir `index.html` directamente en el navegador o servir esta carpeta con cualquier servidor estático.

## Estructura

- `index.html`: estructura semántica, SEO básico y contenido.
- `css/style.css`: sistema visual responsive, layout y componentes.
- `css/testimonials.css`: testimonios demo, focus states y reduced motion.
- `js/script.js`: menú móvil y animaciones al entrar al viewport.
- `assets/logo/`: logo horizontal, versión clara e isotipo.
- `assets/images/`: ilustraciones SVG originales, preparadas para reemplazarse por fotografías futuras.

## Supuestos

El número de WhatsApp provisto se dejó configurado como enlace de contacto de ejemplo (`549123456789`); reemplazarlo por el número real en formato internacional antes de publicar. Instagram y Facebook quedan como enlaces de muestra.

Los testimonios están marcados como `DEMO` para no presentarlos como opiniones reales.
